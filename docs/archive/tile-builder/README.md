# Tile builder (dropped experiment, 2026-11-16)

A draggable tile palette on an expandable grid, with a live preview, that logged into the same grid. Dropped because building a table is too much setup for the speed and simplicity goal; see CASE_STUDY.md. These files are kept for reference only and are not part of the app (they are outside app/src). To revive it, copy them back to app/src/screens (GridBuilder, GridView) and app/src/core (grid, grid.test), and restore the wiring described in the case study.
